GitHub connection

Connect to save text edits

To let this page save text changes to your live site, paste a GitHub access token below (created once, stays only on this device — never uploaded anywhere).

  1. On GitHub, go to your profile picture → Settings → scroll down to Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access: choose Only select repositories → pick yourclipswebsite.com
  4. Under Permissions → Repository permissions, set Contents to Read and write
  5. Generate, then copy the token (starts with github_pat_...) and paste it below
